# Tooded — настольный магазин

C# / WinForms / .NET 8. Интерфейс доступен на эстонском, русском и английском языках.

## Открыть в Visual Studio

1. Распакуйте архив целиком.
2. Откройте **Tooded.sln** в Visual Studio 2022 17.8 или новее с компонентом **Разработка классических приложений .NET** и .NET 8 SDK.
3. Дождитесь восстановления пакетов NuGet (при первом запуске нужен интернет).
4. Нажмите **F5**. Стартовый проект — Tooded_EFCore.

Демонстрационные учётные записи, создаваемые при первом запуске:

| Роль | E-mail | Пароль |
|---|---|---|
| Администратор | admin@admin.ee | admin123 |
| Покупатель | kasutaja@pood.ee | kasutaja123 |

Это учебные аккаунты. Перед реальным использованием замените их.
Окна собираются программно в файлах Form*.cs; Designer.cs содержит стандартную оболочку формы.

## Что работает

- Единое окно, боковое меню и выход из учётной записи.
- Каталог: поиск, категории, сортировка по цене, остатки и фотографии товаров с Pexels, доступные без интернета.
- Загрузка собственных фотографий товаров.
- Корзина: добавление, изменение количества, удаление строк, расчёт суммы.
- Проверка актуальных цен и остатков перед созданием PDF.
- PDF с несколькими страницами, выбор места сохранения и открытие последнего документа.
- Управление товарами для администратора: добавление, редактирование, удаление.
- Отправка PDF через настроенный SMTP. Отправка асинхронная, ошибки показываются в интерфейсе.

Корзина хранится в памяти сеанса и очищается при выходе. Создание/отправка PDF не является оплатой и не списывает склад. Завершение заказа и история продаж в этой версии не реализованы.

## Данные

По умолчанию SQLite автоматически создаёт файл:
%LOCALAPPDATA%\ToodedApp\tooded.db

Фотографии — Images, счета по умолчанию — Arved в той же папке.
В новую SQLite-базу добавляются восемь демонстрационных товаров.
Переменная среды TOODED_DATA_DIR позволяет выбрать другую папку данных.

Существующая SQL Server-база не изменяется и не переносится автоматически.
Для её использования задайте переменную среды TOODED_SQLSERVER, например:
Server=(localdb)\MSSQLLocalDB;Database=Tooded_DB;Trusted_Connection=True;TrustServerCertificate=True;

После изменения переменных среды перезапустите Visual Studio.
Для SQL Server сохранён исходный механизм миграций; для SQLite используется EnsureCreated.
При изменении модели SQLite потребуется отдельная миграция/перенос данных.

## Язык и фотографии

Переключатель Eesti / Русский / English находится на экране входа и в боковом меню.
Язык применяется сразу и сохраняется в language.txt в папке данных приложения.
Корзина и введённые поля при переключении сохраняются.
Переведены сообщения, заголовки таблиц, PDF-счета и текст исходящего письма.
Восемь демонстрационных названий и три категории переводятся для показа;
названия, самостоятельно введённые администратором, остаются как введены.
Поиск работает и по исходным, и по переведённым названиям.
Если нужен PDF на другом языке, выберите язык и сохраните счёт заново.

Фото находятся в Assets/Products и копируются в папку сборки автоматически.
Авторы и ссылки перечислены в Assets/PHOTO_CREDITS.md.
Существующая база не переписывается: фото подставляются для исходных демо-названий.
Свои загруженные фото имеют приоритет. Для остальных товаров остаётся иллюстрация-заглушка.
Словарь переводов — Assets/translations.json, механизм привязки интерфейса — L.cs.

## Настройка почты

Пошаговая инструкция для Gmail, настройки Windows и решение ошибок — **EMAIL_SETUP.md**.

Задайте переменные среды перед запуском:
- TOODED_SMTP_HOST — адрес SMTP-сервера
- TOODED_SMTP_PORT — порт (по умолчанию 587)
- TOODED_SMTP_USER — адрес отправителя / логин
- TOODED_SMTP_PASSWORD — пароль приложения

Используется STARTTLS. Без настройки SMTP сохранение PDF работает.
Пароль из исходного репозитория удалён из текущего кода. Он был опубликован в Git: его нужно отозвать у почтового провайдера; удаление строки не отзывает пароль и не очищает историю Git.

## Проверка

Release-сборка: 0 ошибок, 0 предупреждений.
Локальные интеграционные проверки на изолированной SQLite-базе:
создание базы и категорий; сохранение товара; поиск и пустой результат;
запрет отрицательного количества и превышения остатков;
объединение одинаковых товаров, сумма и изменение количества;
создание многостраничного PDF.
Окна проверены через рендеринг реальных WinForms-контролов.
Дополнительно проверены переключение ET → RU → EN → ET без перезапуска,
сохранение корзины и несохранённых полей/категории, поиск по русским названиям,
сохранение языка и генерация PDF на всех трёх языках. Русская кириллица в PDF
проверена извлечением текста и визуальным рендерингом.
SMTP и подключение к существующей SQL Server-базе не проверялись.

Команды:
dotnet restore Tooded.sln
dotnet build Tooded.sln -c Release

На машине проверки установлен .NET 10; тестовый запуск .NET 8 выполнялся с DOTNET_ROLL_FORWARD=Major. Целевой framework проекта остаётся net8.0-windows.

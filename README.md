# Tooded — настольный магазин

C# / WinForms / .NET 8. Интерфейс на эстонском языке.

## Открыть в Visual Studio

1. Распакуйте архив целиком.
2. Откройте **Tooded.sln** в Visual Studio 2022 17.8 или новее с компонентом **Разработка классических приложений .NET** и .NET 8 SDK.
3. Дождитесь восстановления пакетов NuGet (при первом запуске нужен интернет).
4. Нажмите **F5**. Стартовый проект — Tooded_EFCore.

Демонстрационные учётные записи, создаваемые при первом запуске:

| Роль | E-mail | Пароль |
|---|---|---|
| Администратор | admin@admin.ee | admin123 |
| Покупатель | kasutaja@pood.ee | kasutaja123 |

Это учебные аккаунты. Перед реальным использованием замените их.
Окна собираются программно в файлах Form*.cs; Designer.cs содержит стандартную оболочку формы.

## Что работает

- Единое окно, боковое меню и выход из учётной записи.
- Регистрация: кнопка «Loo uus konto» на экране входа. Аккаунт хранится в базе (пароль — BCrypt) и остаётся после перезапуска. Новые аккаунты всегда с ролью покупателя.
- Каталог: поиск, категории, сортировка по цене, остатки и фотографии товаров.
- Клик по карточке товара открывает окно с полным описанием (там же можно добавить в корзину).
- Кнопка «Lisa korvi» у отсутствующего товара показывает короткое извинение.
- Подсветка остатков: «Otsas» (0 шт.) — красным, «Lõppemas» (1–5 шт., порог в `Ladu.cs`) — жёлтым; в каталоге и в таблице администратора.
- Корзина: добавление, изменение количества, удаление строк, расчёт суммы, PDF-счёт, отправка по SMTP.
- «Kinnita ost» подтверждает покупку: уменьшает остаток и записывает продажу в таблицу Muugid.

### Администратор

- Не может покупать: в каталоге нет корзины, раздела «Ostukorv ja arve» нет.
- Tootehaldus: товары (с полным описанием) и кнопка «+ Uus» для добавления категорий.
- Ostusoovitused: прогноз закупок на 7/14/30/60 дней по истории продаж. Учитывает день недели, время суток (оставшиеся часы сегодняшнего дня, часы пик), праздники Эстонии (Jõulud, Jaanipäev, Lihavõtted, Sõbrapäev, Emadepäev, Isadepäev, Mardipäev, Kadripäev и др.) и тренд спроса. Праздничные коэффициенты берутся из самой истории продаж, а не задаются вручную.
- Demo klient: открывает настоящее окно магазина с правами гостевого покупателя без регистрации. Работают каталог, поиск, карточки и отдельная корзина. Кнопка «Proovi ostu» завершает пробную покупку без записи продаж и списания остатков. Кнопка «Tagasi adminiks» или закрытие окна возвращает администратора.

В новую SQLite-базу добавляется демо-история продаж за два года (помечена как Demo), чтобы рекомендации работали сразу. Её можно удалить кнопкой «Eemalda demoajalugu» на экране рекомендаций; настоящие покупки при этом сохраняются. Для товаров, добавленных администратором, нужна собственная история продаж (минимум ~4 недели и 10 продаж), до этого рекомендации опираются только на остаток.

Корзина хранится в памяти сеанса и очищается при выходе. Остаток списывается кнопкой «Kinnita ost». После успешной покупки появляется вопрос «Kas soovid tšekki?».

## Данные

По умолчанию SQLite автоматически создаёт файл:
%LOCALAPPDATA%\ToodedApp\tooded.db

Фотографии — Images, счета по умолчанию — Arved в той же папке.
В новую SQLite-базу добавляются восемь демонстрационных товаров.
Переменная среды TOODED_DATA_DIR позволяет выбрать другую папку данных.

Существующая SQLite-база при запуске дополняется колонкой описания и таблицей продаж без потери данных. Для SQL Server добавлена миграция LisaMuugidJaKirjeldus (применяется через Migrate).
Существующая SQL Server-база не переносится автоматически.
Для её использования задайте переменную среды TOODED_SQLSERVER, например:
Server=(localdb)\MSSQLLocalDB;Database=Tooded_DB;Trusted_Connection=True;TrustServerCertificate=True;

После изменения переменных среды перезапустите Visual Studio.
Для SQL Server сохранён исходный механизм миграций; для SQLite используется EnsureCreated.
При изменении модели SQLite потребуется отдельная миграция/перенос данных.

## Язык и фотографии

Выбор языка убран: интерфейс всегда на эстонском.

Фото находятся в Assets/Products и копируются в папку сборки автоматически.
Авторы и ссылки перечислены в Assets/PHOTO_CREDITS.md.
Существующая база не переписывается: фото подставляются для исходных демо-названий.
Свои загруженные фото имеют приоритет. Для остальных товаров остаётся иллюстрация-заглушка.
Словарь переводов — Assets/translations.json, механизм привязки интерфейса — L.cs.

## Настройка почты

Пошаговая инструкция для Gmail, настройки Windows и решение ошибок — **EMAIL_SETUP.md**.

Задайте переменные среды перед запуском:
- TOODED_SMTP_HOST — адрес SMTP-сервера
- TOODED_SMTP_PORT — порт (по умолчанию 587)
- TOODED_SMTP_USER — адрес отправителя / логин
- TOODED_SMTP_PASSWORD — пароль приложения

Используется STARTTLS. Без настройки SMTP сохранение PDF работает.
Пароль из исходного репозитория удалён из текущего кода. Он был опубликован в Git: его нужно отозвать у почтового провайдера; удаление строки не отзывает пароль и не очищает историю Git.

## Проверка исправленной версии

В DemoData.cs исправлена ошибка CS1061: добавлен импорт Microsoft.EntityFrameworkCore.
Прежняя автоматическая симуляция DemoForm заменена гостевым магазином. Устранены четыре предупреждения CS8602.

Оформление покупки вынесено в Ostuteenus: условное списание остатка и запись
продажи выполняются в одной транзакции. Если остаток или цена изменились,
покупка отклоняется целиком. Повторное добавление товара обновляет цену в корзине.
Ошибки чтения базы при изменении количества и создании PDF показываются в форме.
Создание папок данных включено в обработку ошибок запуска; словарь переводов
загружается только при необходимости. Путь к SQLite корректно обрабатывает
специальные символы благодаря SqliteConnectionStringBuilder.

Проверено в Linux с .NET SDK 8.0.427:

```sh
dotnet build Tooded.sln -c Release -p:EnableWindowsTargeting=true
dotnet run --project Tests/Checks.csproj -c Release
```

на временной SQLite-базе: создание и обновление схемы без потери товаров,
успешная покупка, полный откат при нехватке товара, изменение цены, устаревший

проекта; заменён только вспомогательный класс папок, зависящий от изображений.
Дополнительно проверены гостевой режим без создания аккаунта, отдельная корзина,

## Проверка по учебной инструкции от 16.11.2026

.NET 8 оставлен по согласованию. Функции инструкции реализованы: загрузка
категорий и товаров, добавление/изменение/удаление товаров, выбор изображения,
заполнение полей при выборе товара, добавление и удаление категорий.
Добавление и изменение товара используют общую кнопку «Salvesta toode»;
«+ Uus toode» сбрасывает выбор для добавления.

Добавлена кнопка «Kustuta kategooria»: удаляется только пустая категория.
Проверка отсутствия товаров и удаление выполняются одним SQL-запросом;
занятая категория не удаляет товары и продажи каскадом. Удаление доступно
только администратору. Цена допускает 99999999,99; названия новых товаров
ограничены 100 символами, категорий — 50. При ошибке открытия главного окна
восстанавливается окно входа и очищается сеанс. Гостевое демо сохранено.

Отличия от буквального выполнения инструкции: EF Core вместо прямого ADO.NET,
SQLite по умолчанию вместо вложенного Tooded.mdf, таблицы Toodetabel и
Kategooriatabel вместо Tooted и Kategooriad, программная компоновка форм.
SQL Server/LocalDB можно подключить переменной TOODED_SQLSERVER, но это
не равнозначно наличию файла Tooded.mdf в проекте. Эти отличия не скрыты
и не означают полного соответствия структуре учебного примера.

Проверки SQLite включают удаление пустой категории, отказ для занятой,
сохранность товаров/продаж, отказ покупателю и повторное удаление.
WinForms, фотографии, PDF, SMTP и реальный SQL Server требуют отдельной
проверки в Windows; здесь проверены компиляция и логика SQLite.

## Чек после покупки

Подтвердите покупку и ответьте на вопрос «Kas soovid tšekki?» (Желаете чек?).
«Да» автоматически сохраняет PDF в папке Arved и открывает его. «Нет» завершает
покупку без открытия PDF. Последний чек можно позже открыть, сохранить копию
или отправить по почте из корзины, пока пользователь не вышел из аккаунта.
Чек содержит уникальный номер, дату и время, товары, количество, цены и итог.
Состав чека фиксируется при покупке и не зависит от дальнейших изменений корзины.
При ошибке PDF или SMTP покупка остаётся завершённой; повторная выдача чека
не списывает остатки. Гостевой режим выдаёт чек с пометкой DEMO.
Это чек учебного магазина, без интеграции с платёжной системой или фискализации.
Для почты нужна настройка SMTP из EMAIL_SETUP.md. Сам PDF работает без SMTP.
